# 새 박스(흰 종이 + 검은 가이드) 대응 수정 — 보류 중

환경(박스, 마커 위치)을 확정한 뒤 다시 돌아와서 적용/재검증할 작업. 아직 커밋/적용하지 않았다.

## 파일
- `new_rig_measurer.patch` — `scan/nail_measurer.py`에 대한 수정(git diff). 적용: `git apply scan/pending_new_rig/new_rig_measurer.patch`
- `test_mixed_background.py` — 위 수정용 테스트. 패치를 적용한 뒤 `scan/tests/`로 옮겨서 실행 (패치 없이는 실패한다).

## 패치 내용
1. `detect_free_edge`: 손 양옆 배경이 서로 다르면(L 표준편차 > 20, 예: 흰 종이 + 검은 가이드) 손끝 바로 위 배경을 기준으로 삼는다. 이게 없으면 매트 위로 튀어나온 흰 끝(2~4mm)을 못 잡는다.
2. `grow_shadowed_skin` + `measure_top` 래퍼(본체는 `_measure_top`으로 이름 변경): 한쪽이 그늘진 사진에서 잘린 손가락 마스크를 되살려 한 번 더 잰다. 손톱 구간 마스크가 10% 이상 늘 때만 동작.

## 검증 (2026-10-19, 사진 1장 + 기존 results 40장)
- 새 배경 사진: 폭 8.66 → 11.9mm(눈으로 잰 값 ≈11.9), 손톱 끝 맞음, 길이는 가이드 선이 맞아야 ≈17.6mm(눈 ≈19mm).
- 기존 40장: 37장 동일, 3장 흰 끝 1px(0.1mm) 차이.
- 캘리퍼 실측값은 없다. 새 박스에서 여러 손가락/여러 사람으로 다시 확인 필요.

## 환경 확정 때 같이 정할 것
- `scan/nail_live.py`의 `GUIDE_LINE_OFFSET_MM`(현재 마커 아래 +9mm). 새 박스에서는 큐티클이 마커 아래 끝 근처(≈0mm)에 온다. 9mm 그대로면 이 사진은 길이가 30mm로 나온다. 마커 위치를 바꾸면 다시 정해야 한다.
- 마커 윗면과 손톱 높이 차이: 높이가 다르면 mm/px 스케일이 어긋나 폭·길이가 같은 비율로 틀어진다.
- 긴 손톱(길이/폭 ≈1.6)은 가이드 선 없이 자동으로만 재면 큐티클이 짧게 잡힌다(`CUT_PLATE_RATIO_MAX = 1.40`). 가이드 선에 맞춰 찍는 촬영에서는 문제없다.
- 피부색(초록/흰 종이 반사광), 폰 측면(C-curve) 촬영은 이번에 확인하지 않았다.
