2. 쉐입 ↔ 무드

4. 세트 구성 (세 가지 디자인이 번갈아)

  • 세트는 기본적으로 정확히 3가지 디자인이 번갈아 나옴: 두 디자인이 각 2개, 하나가 1개 (A B A C B 또는 A B C A B)
  • "디자인" = 색 효과(글리터·자석·파우더·니트·잉크) 또는 베이스 패턴(그라데이션·마블·프렌치·치크·블루밍…) 또는 원컬러
  • 사용자가 고른 디자인은 항상 포함되지만 한 디자인은 최대 2개 손톱, 5개 전체 금지. 이웃 손톱에 같은 디자인 금지. 같은 디자인이라도 작은 장식·방향이 달라야 함
  • 색 효과는 시럽 외에 세트당 최대 1종. 베이스 디자인은 세트당 최대 3종, 손톱당 1개
  • 모자란 디자인을 채우는 기본 풀: 원컬러 5, 그라데이션 5, 글리터 2, 마블·프렌치·치크·파우더 각 1 (가을/겨울은 니트 +2, 펑키/시크는 블루밍 +2). 이 풀에 색 톤·손 특성 가중치를 곱해서 뽑음(5번)
  • 시럽이 기본: 모든 손톱의 색 표현이 시럽(반투명). 글리터·파우더·잉크는 시럽 위에 올림. 솔리드는 사용자가 요청할 때만
  • 풍성함: 심플 키워드가 없으면 손톱 중 최대 1개만 조용하게, 나머지는 눈에 보이는 장식(모티프·파츠·패턴) 하나 이상

  • 색-디자인 매칭: 파스텔 → 소프트 그라데이션·치크·프렌치 / 비비드 → 원컬러·컬러 팁 / 짙은 색 → 자석·글리터·마블(치크 제외)

6. 무작위 변주 힌트 [VARIATION LEAN] (요청마다 랜덤으로 제안, 강제 아님)

참 모양

작은 폴리시드 실버 메탈 참작은 아이보리 불투명 레진 참투명 클리어 레진 3D 참글로시 캔디·진주빛 아크릴 참묵직한 조각 크롬 실버 참무광 블랙 에나멜 참

장식 위치

큐티클 근처팁 모서리한쪽 측면대각선 일렬작게 흩뿌림프리 엣지를 따라

표현 방식

도톰한 글로시 젤(입체)번지는 수채화(평면)

창작 트위스트 12종 (2개를 랜덤 제안)

  • 평소와 다른 손가락을 가장 화려하게, 이웃은 아주 조용하게
  • 중앙이 아니라 한쪽 벽/프리엣지에 붙인 비대칭 배치
  • 네거티브 스페이스: 한쪽 모서리에 아트를 모으고 나머지는 비움
  • 부분·역방향 프렌치(코너, 사이드, 얇은 더블 프렌치)
  • 그라데이션을 대각선이나 팁에서 시작
  • 한 손톱을 두 컬러 블록(반반)으로 분할
  • 히어로 손톱의 작은 요소를 다른 손톱에 다른 크기로 반복
  • 세트에 마감 두 가지 섞기(시럽 사이에 크롬 포인트 한 손톱)
  • 팔레트 색 하나를 한 번만 쓰는 의외의 손톱

8. 코드 안전장치 (GPT가 규칙을 어길 때 보정)

  • enforceCombinationRules / ensureSyrupDefault / limitColorExpressions — 조합 규칙, 시럽 기본, 색 효과 세트당 1종
  • enforceNoDrawnRibbon — 드로잉/큐트가 아니면 그린 리본을 3D 리본 참으로
  • enforceInkForDrawing — 드로잉이면 잉크 손톱 보장
  • enforceDotRules / enforceHandDrawnCheck — 도트, 손그림 체크
  • enforceBloomingForMood / stripBloomingUnlessMood — 블루밍은 시크/펑키에서만 추가, 그 외엔 제거
  • enforceFunkyParts — 펑키면 파츠 보강
  • enforceRichness — 심플이 아니면 장식 풍성하게
  • stripReferenceWording — 설명에서 "reference" 같은 표현 제거
  • wantedPart — 스캔 자동 안내 블록 안의 예시 단어(funky 등)를 무드/디자인 감지에서 제외
